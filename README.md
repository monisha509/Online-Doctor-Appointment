# Online Doctor Appointment System

A modern, role-based Online Doctor Appointment & Healthcare Management Portal.

## 🌟 Key Features

- **Multi-Role Portal**: Dedicated, responsive dashboards for **Patients**, **Physicians**, and Hospital Administrators.
- **Doctor Directory & Booking**: Search, filter, and schedule appointments with doctors across multiple medical specialties.
- **Patient Dashboard**: Track upcoming appointments, view clinical history, and manage medical records.
- **Physician Dashboard**: Manage patient queues, approve/reschedule appointments, and review daily consultation schedules.
- **Interactive UI**: Built with modern CSS design, animations, clean typography, and mobile-friendly layouts.

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Edge, Firefox, Safari)
- [Node.js](https://nodejs.org/) (optional, for backend API server)

### Running the Frontend
Simply open `login.html` or `index.html` in any web browser.

### Running with Backend (Optional)
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Open your browser at `http://localhost:3000`.

## 📁 Project Structure
- `index.html` / `login.html` - Entry point and role-based authentication
- `home.html` - Main healthcare landing page
- `doctors.html` - Specialist doctors directory & profile cards
- `appointment.html` - Interactive booking wizard & slot selector
- `patient-dashboard.html` - Patient portal with appointment tracking
- `physician-dashboard.html` - Doctor portal with schedule & patient management
- `success.html` - Confirmation page with booking receipts
- `css/` - Custom styling, theme variables, and responsive layout sheets
- `js/` - Frontend application logic, mock authentication, and data services
- `server.js` - Express backend server and SQLite database adapter
